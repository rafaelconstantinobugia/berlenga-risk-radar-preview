# Berlenga Risk Radar — public preview

**Non-official research demonstrator, 17 October 2026.**

This is a static build of the **public portal layout and UX of Lagoa Risk Radar (PEN02)**, adapted for the Berlenga archipelago. It uses the same satellite-map-first layout, overlaid official/water/forecast cards, mobile real/simulation selection, fictitious 0–10 simulation and floating documented-questions interface. Geographical, institutional and environmental claims are specific to Berlengas and labeled according to their evidential quality.

- **ICNF** Reserva Natural das Berlengas boundary is an official ArcGIS geometry, not a precisely surveyed legal boundary.
- **ZEC** conservation management plan MC1–14 (Portaria 103-A/2026/1) consists of official targets; verified progress is **unknown**.
- **Marine forecasts** use Open-Meteo models. The model grid is **not** an on-island in-situ sensor, and the portal does not certify safe navigation or water.
- Historic biodiversity eDNA sampled **2020–2021** via [OBIS / DOI](https://doi.org/10.25607/q3lfh8) is *not* a contemporaneous water-quality measurement.
- All scores in **Demo** are explicitly fictitious. No underlying Lagoa/PEN02 data/API is queried.

This repository intentionally contains only static publication artefacts, **not** private research archives, editable PEN02 source, secrets or administration.
