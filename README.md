# Berlenga Risk Radar — Public MVP Preview

Non-official environmental intelligence prototype for the Berlengas archipelago.

- Static build only, no source code, keys, user information, raw research archives or administration.
- ICNF map via original source; Open-Meteo marine grid forecasts, not measurements on the islands.
- Natura 2000 conservation targets described as legal targets, not completed actions.
- Not a navigation safety, fishing authorization, sanitation or official environmental service.

Build date: 2026-10-17. Hosting: GitHub Pages. Please check original sources for official status.
